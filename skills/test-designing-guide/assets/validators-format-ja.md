| Test Method                                | Verification                                                   |
|--------------------------------------------|----------------------------------------------------------------|
| `<条件>_<期待結果>`                        | `<プロパティ>` が `<期待値または状態>` である                  |
| `<期待結果>`                               | `<プロパティ>` が `<期待値または状態>` である                  |
| `<条件>_<期待結果>` (acceptance test)      | `<プロパティ>` が `<期待値または状態>` である                  |
| `<条件>_<期待結果>` (reproduction test)    | `<プロパティ>` が `<期待値または状態>` である                  |
| `<条件>_<期待結果>` (existing)             | `<プロパティ>` が `<期待値または状態>` である                  |
| `<条件>_<期待結果>` (test fix)             | `<プロパティ>` が `<期待値または状態>` である                  |

**Notes:**

- すべて `<データフォルダ>` 配下の `<ClassName>` ScriptableObject のアセットを引数に取るパラメタライズドテストです
- 条件 `<条件>`、`<条件>` は、振る舞いが「未定義」と仕様に明示されているため、テストケースに含まれません
- unverifiable, undefined, ambiguous と書かれたテストケースからは、テストコードは生成されません
