# カードドロー画面 仕様

## 画面構成

| 画面       | 内容                                   |
|------------|----------------------------------------|
| タイトル   | 「はじめる」ボタン                     |
| ドロー画面 | 残り回数の表示、「引く」「戻る」ボタン |
| 結果画面   | 引いたカードの表示、「次へ」ボタン     |

各画面にあるボタンは上記だけで、記載のないボタンはない。
アプリ起動直後はタイトルを表示する。

## 残り回数

- アプリ起動時の残り回数は 3 回
- 「引く」を押すたびに 1 減る
- 残り回数が 0 のとき「引く」ボタンは非活性で、押しても何も起きない
- 残り回数はタイトルに戻っても保持される
- 残り回数が 0 の状態でタイトルから「はじめる」を押すと、残り回数は 3 に戻る。1 以上なら保持される

## 画面遷移

- タイトルで「はじめる」を押すとドロー画面へ遷移する
- ドロー画面で「引く」を押すと、カードを 1 枚引いて結果画面へ遷移する
- ドロー画面で「戻る」を押すとタイトルへ遷移する
- 結果画面で「次へ」を押すとドロー画面へ遷移する

## カード

- 引けるカードは「赤」「青」「緑」の 3 種類で、どれが出るかはランダム。出現率は均等で、毎回独立に決まる
- 結果画面には引いたカードの色の名前をテキストで表示する
